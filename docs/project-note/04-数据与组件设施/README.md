## 本分类的四条硬事实

1. **无前端框架**：`app.js` 是纯函数 + `innerHTML` 拼接，所有插值必须过 `esc()`（`internal/panel/app.js:88-95`）。
2. **无 cookie/无服务端会话**：面板密钥在 `localStorage`，每请求 Bearer（`app.js:65-77`）。
3. **状态容器 11 个，落盘的只有 8 个**：降级/预算/WAF/任务去重/探索 timer 重启即丢，这是设计而非疏漏。
4. **`livecfg.Store` 是整体覆盖**：新增热字段必须同时改启动装配与面板保存两处，否则保存后变零值。
