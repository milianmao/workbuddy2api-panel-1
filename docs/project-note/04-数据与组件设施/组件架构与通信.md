# 组件架构与通信

本项目没有 React/Vue："组件"是 `index.html` 里的静态骨架 + `app.js` 里的视图函数。所有状态在模块级 `let` 变量里，没有响应式框架。

## 三个文件与体积

| 文件 | 行数 | 职责 |
|---|---|---|
| `internal/panel/index.html` | 1615 | 全部骨架与 CSS；8 个 `<section class="view" hidden>` |
| `internal/panel/app.js` | 4669 | 全部逻辑：路由、渲染、请求封装、轮询 |
| `internal/panel/theme.js` | 27 | 首屏主题预热（`<head>` 同步外链，早于样式表） |

三者经 `go:embed` 打进二进制（`internal/panel/index.go:20-26`），**无打包步骤**。

## 视图树

```
/panel/  →  index.html
├── 账号池        accounts     #view-accounts   index.html:748
├── 用量          usage        #view-usage      :1026
├── 积分构成      packages     #view-packages   :1003
├── 余额趋势      balhist      #view-balhist    :948
├── 任务中心      taskscenter  #view-taskscenter:834
├── 模型与档位    models       #view-models     :890
├── 配置          config       #view-config     :1112
└── 运行日志      logs         #view-logs       :1361
```

hash 路由：`history.replaceState` 写 `#view`，`go()` 切换 `.view[hidden]` 并按需懒加载（`internal/panel/app.js:430-456`）；首次进入用 `setTimeout(0)` 延后一次 `go()`，避开模块级 `let` 的 TDZ（`:451-456`）。标题映射在 `TITLES`（`:431`）。

## 数据流与通信

```
用户点击 → 视图函数（renderXxx）
        → api(path)  ── fetch('/panel/api/' + path, {Authorization: Bearer localStorage[...]})
                │
                ├─ 401 → 弹密钥门（modal），阻止后续渲染
                └─ 其它错误 → throw，错误挂 e.status 供调用方分支
        ← JSON → 直接拼字符串写 innerHTML（全部出口经 esc() 转义）
```

- 请求封装：`api(path)`（`app.js:65-77`）。**无 cookie**：密钥存 `localStorage['wb2api.key']`，每请求带 Bearer；「登出」= 删 key + reload（`:419-424`）。
- XSS 防线：`esc()` 5 字符转义，所有插值必须经过它（`app.js:88-95`）。CSP `script-src 'self'` 禁内联，因此 `theme.js` 必须外链文件（`index.go:90-93`）。
- 轮询：全局 5s `refreshVisible()` 只按当前 view 拉对应数据（`app.js:1792-1809`）；登录 3s（`:1644`）；账号作业 3s（`:2021`）；任务队列 3s 且结束即 `clearInterval`（`:2306-2320`）。**补偿/券码/模型目录不进 5s 轮询**，避免每 5 秒打上游（`:3664-3666`、`:1799-1803`）。
- 主题：`localStorage['wb2api.theme']`，`auto|light|dark`；`auto` 跟随 `prefers-color-scheme`（`app.js:3`、`:30-47`；`theme.js:17-26`）。

## 前端可测试性约定

CI 用 node 校验 `app.js`，无 node 时 skip（`internal/panel/frontend_test.go:20-40`、`:58-130`、`:186-260`）：

- **语法与顶层求值**：`os.CreateTemp(t.TempDir(), …)` 跑 JS 片段；
- **关键纯函数**：转义、格式化、归属判断等被单独抽出为纯函数以便断言；
- **无 DOM 依赖的渲染契约**：如「任务中心空态/归属标志」有专门用例（`frontend_test.go:262-300`）。

因此改 `app.js` 时：纯函数必须保持可独立求值（不依赖 DOM 全局），否则测试静默 skip。
