# 成长任务队列与账号接入

两条相互衔接的链路：账号怎么进池（三条接入路径，全部落 `Hold` 暂停选号），以及进池后怎么自动赚积分（成长任务队列两套执行器）。

## 触发点

**账号接入**：
- OAuth 设备流：`POST /panel/api/login/start` → 用户在浏览器授权 → `GET /panel/api/login/poll`（前端每 3s 轮询，连败 20 次停，`internal/panel/app.js:1644`、`:1689`）。
- JSON 导入：`POST /panel/api/import/cockpit`（multipart，上限 32 MiB，支持一次多选多个文件）。
- 静态 API Key：`POST /panel/api/accounts/add_apikey`（`ck_`/`pt_` 前缀）。

**成长任务**：
- 手动：`POST /panel/api/tasks/run_queue`（`{concurrency:1-4}`）或单号 `tasks/auto` / `tasks/auto_all`。
- 新号自动：登录/导入成功后 `StartNewAccountTasks`（`trigger=new_account`）。
- 排程：`growth_hours`（默认 11）→ `RunGrowthQueueNow` → 每号启一个 `trigger=daily` 作业。
- 补领清扫：每 15min 只做 accept 待接受 + claim 已达标未领。

## 数据流路径

**OAuth 登录**：`login/start` → 按站点（cn/intl/workbuddy）取 `loginsite` 域名表 → `POST /v2/plugin/auth/state?platform=CLI` 拿 state + authUrl → 补 `version=`（workbuddy 域再加 `ww_device_nonce`）→ state 存内存（15min TTL）→ 返回 URL 给浏览器 → `login/poll` → `GET /v2/plugin/auth/token?state=` → 码表判定（`11217`/`12151` 继续轮询；`12005`/`11212`/`11216` 终态）→ 成功 → uid 白名单校验（防路径穿越）→ `MkdirAll` → 写 `auths/workbuddy-<uid>.json`（嵌套形 + realm，`0600`）→ `Pool.Add` → `Revive` → **`Hold`（暂停选号）** → 按 realm 做 global 注册激活 + trial，或 CN 签到 → 余额校验 → `StartNewAccountTasks`。

**成长任务**：`RunGrowthQueueNow` → 遍历 `Pool.List()` 跳过 disabled/global → `StartAccountTaskJob(uid,"daily")` → 后台执行器 `runAutoAllObserved`：批量 accept（默认口径 + mp 口径）→ 按 `autoActions` 顺序逐项执行（每项真实动作：对话/上报/领养…）→ 达标回读（4 次 × 3s）→ claim（web 域路径）→ 结果写作业 `results` → 原子落盘 `task-jobs.json`。

## 异常处理

- OAuth token 端点返回未知码：按 pending 处理，前端继续轮询直到 20 次失败放弃（不写 auth 文件）。
- uid 非法/缺失：拒绝落盘，返回错误（防路径穿越写任意文件）。
- 导入格式不认识：该条目 skip 并计数；整体仍返回成功条目统计。
- API Key 前缀不是 `ck_`/`pt_`：400 拒绝。
- API Key 探测失败：400 且不落盘（避免落一个必然 401 的号进池）。
- 静态 Key / 企业号：无 refresh token、`NeedsRefresh` 恒 false，不参与 token 保活；无个人成长体系 → 跳过成长任务与补领清扫。
- 新号落池即 `Hold`：不接选号，需显式「恢复选号」；"解冻"/签到回血**清不掉**该状态（`66908b3`/`320bedd` 端到端钉死）。
- 作业中断：进程退出时残留 `pending/running` 改写为 `interrupted` 并落盘；`ResumeTaskJobs` 启动按 UpdatedAt 恢复。
- 作业超上限：淘汰最旧非活动作业（活动作业永不淘汰）。
- 任务队列未启用（`schedule.growth_enabled=false`）：非手动触发一律 403；手动入口照旧。
- 领奖失败：不重试，靠补领清扫兜住（一天一轮 + `autoActions` 白名单外的漏领）。
- 账号正在执行：`TryLock` 失败即让位，本轮不排队。
