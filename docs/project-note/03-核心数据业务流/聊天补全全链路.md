# 聊天补全全链路

从客户端 `POST /v1/chat/completions` 进入，到 SSE 最后一个 `data: [DONE]` 写出为止。Responses / Anthropic Messages / 图像三条入口都汇入这条主链路（各自做协议翻译后复用同一轮转与中继逻辑）。

## 触发点

- 触发方式：HTTP `POST /v1/chat/completions`（`internal/server/handler.go:192`）；协议翻译入口 `POST /v1/responses`（`:193`）、`POST /v1/messages` 与 `/messages`（`:199-200`）、`POST /v1/images/generations` 与 `/edits`（`:197-198`）。
- 鉴权前置：`api_key` 非空时校验 `Authorization: Bearer`（OpenAI 形状 401）或 `x-api-key`（Anthropic 形状 401）；`api_key` 为空直接放行（`handler.go:261-268`、`internal/server/messages.go:20-33`）。
- 前置状态要求：无（账号池为空也能进，末端 503）。请求体**无网关侧大小上限**，完整读入（`handler.go:721-728`）。

## 数据流路径

`POST /v1/chat/completions` → 日/突发预算闸 `budget.admit()` → 读 body（无上限）→ 窥探 `{stream, model}` → 取工具名名单 → 解析 realm 前缀 → `models.aliases` 映射 → hidden 黑名单检查 → 提取会话键（`ExtractKey`）与派生缓存键（`DeriveCacheKey`）→ 解析粘性绑定（`ResolveForModel`）→ 提示词模式改写 + `EnsureSystemFirst` → 生成会话头族（循环外一次）→ **轮转循环 ≤ MaxRotate(3)**：粘性号 `PickByUIDForModel` / 普通 `PickExcludingForRealm` → `Pool.Acquire` 占在途名额 → 必要时 `RefreshTokenIfNeeded` → `Upstream.ChatStreamContext` 转发 → **首帧检查**（`HeadVetoError` 则换号）→ 成功即 `NoteSuccess` + `X-Wb-Account` + `BlockModelClear` + `Session.Bind` → SSE 中继（`StreamHint` 白名单重建 + 恰好一个 `[DONE]`）或非流式 `Aggregate` → 用量/扣费记账（`usage.Add` + `Pool.RecordTokenUsage` + `NoteModelCost`）→ 释放租约 `Pool.Release` → 统计落 `reqlog` 与 stdout 流水行。

## 异常处理

- 客户端断连（ctx 取消）：等待循环立刻 `break`，outcome 记 `interrupted`，且不喂连败计数——传输错误是断连的结果而非账号的错，否则几次断连就能把整池逐个降权（`handler.go:1174-1178`）。
- `ErrHardCredit`（402 或 429+14018）：`CooldownUntilTomorrow4AM` 硬冷却至次日 04:00 CST，换号；全池都是这一种 → 429 `insufficient_quota`（`handler.go:1897`、`:1658-1663`）。
- `ErrSoftRate` 带重置墙钟（6004 模型级）：`CooldownSoftForModel` 精确冷却到该墙钟，切模型豁免；冷却记在**原模型**名下（`handler.go:1899-1912`）。
- `ErrSoftRate` 无墙钟：`CooldownSoftRate` 有界指数退避，封顶 `soft_rate_max`（默认 2h）（`internal/pool/cooldown.go:549-565`）。
- `ErrSoftRate` + 14003 模型繁忙且无墙钟：`CooldownModelBusy` 独立短窗口（10s 起、封顶 1min），不套 600s 阶梯（`handler.go:1918-1926`）。
- `ErrWafBlock`：软冷却（60s 基数 ± 抖动），不禁用；60s 窗内 ≥2 个不同 UID 命中 → 判 IP 级拦截、激活 60s 且当场终止轮转（`internal/server/wafip.go:29-35`、`handler.go:1362-1364`）。
- `ErrSessionDead` 业务码 12153：一次即 `Disable`，等人工重登（`handler.go:2001`）。
- `ErrSessionDead` 网关 401（APISIX HTML）：先 `VerifySessionByRefresh` 三分判词，alive → `ClearSessionDead` + 软冷却；inconclusive → 只软冷却；dead → `NoteSessionDeadWith` 连续 3 次才禁用（`handler.go:1968-2000`）。
- `ErrModelBlocked`（11102/11158）：写 (账号,模型) 负缓存 `BlockModelBackoff`（6h 起、封顶 24h），换号或换模型（`handler.go:2066`）。
- `ErrContentBlocked`：passthrough/append 首遇 → 触发降级（至次日 00:00 CST）并用 `prompt.Degraded` 同请求重试一次；第二次仍拦 → 400 `content_blocked` 透传上游原文，**不罚号不轮转**（`handler.go:1228-1256`、`internal/server/degrade.go:22-52`）。
- `ErrPromptTooLong`（11115）：400 `prompt_too_long` 透传原文，不罚号不轮转（`handler.go:1264`）。
- `ErrUpstreamBusy`（6021）：503 `upstream_busy` + `Retry-After`，不罚号不轮转（`handler.go:1288-1306`）。
- `ErrToolMismatch`（11148）：400 `tool_call_mismatch`，不罚号不轮转（`handler.go:1310-1326`）。
- `ErrBadParams`（11101）/ `ErrModelParamInvalid`（11133）：400 透传原文，不罚号不轮转（`handler.go:1335-1350`）。
- `ErrImageInvalid`（11135）：400 `image_invalid`，不罚号不轮转（`handler.go:1279`）。
- 空流：已提交头时补一帧 `error` 再补 `[DONE]`，返回 `errEmptyStream`，handler 记 502 观测（`internal/upstream/sse.go:917-932`）。
- 截断：聚合时既无 `finish_reason` 也无 `[DONE]` → 报 `finish_reason="length"`，并丢弃 arguments 不可解析的 tool_call（`sse.go:257-259`、`:285-287`）。
- 模型级阻塞（选号返回 nil 但号都在）：`modelBlockIsTransient` 为真 → 503 `model_busy` + `Retry-After`（可先为「模型繁忙」等一轮，等待不占换号次数）；否则 400 `model_unavailable`（`handler.go:1655-1705`、`:1090-1092`）。
- 全池在途占满：`Acquire` 逐个失败 → 换号耗尽 → 503 `no_healthy_account`（`handler.go:1112-1123`）。
- 空输出（`finish_reason=length` + 正文 0 字节 + 无 tool_calls + 显式限额）：同预算关 `thinking` 重发一次，每请求只救一次；限额 <16 不救（`internal/server/starved.go:37-87`）。
