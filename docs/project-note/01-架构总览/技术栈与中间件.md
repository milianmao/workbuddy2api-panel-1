## 数据存储

| 存储 | 格式 | 路径 | 写入方式 |
|---|---|---|---|
| 账号凭证 | JSON（嵌套形/扁平形双兼容），`0600` | `auths/workbuddy-<uid>.json` | `safefile.WriteKeep`（fsync + rename + `.bak`） |
| 池状态 | JSON | `data/state.json` | 5s 定时 flush + 信号时强制 flush |
| 用量分桶 | JSON | `data/usage.json` | 同 state 目录（路径由 `state_file` 推出） |
| 模型上限缓存 | JSON | `data/model.json` | embed 种子 + 原子写回 |
| 余额趋势 | JSON | `data/balance_history.json` | 定时采样 |
| 积分变动流水 | JSON（上限 2000 条） | `data/credit-history.json` | 余额观测回调 |
| 任务作业 | JSON | `data/task-jobs.json` | 重启恢复未完成作业 |
| 任务归档 | JSON | `data/task-logs.json` | 失败只 WARN |
| 启动补跑去重 | JSON | `data/task-runs.json` | 同日只补一轮 |
| 模型上限探测 | JSON | `data/output_probes.json` | `scripts/probe_max_tokens.py --panel-out` 写 |
| 请求归档 | JSONL（日切，保留 7 天，上限 100 MiB） | `data/request-logs/` | `reqlog` 异步队列，满了丢弃并计数 |
| 管理操作审计 | JSONL | `data/admin_audit.log` | `admin.audit_enabled` |
| 上游抓包 | 文本 | `upstream.dump_dir` | 诊断用，单文件封顶 8MB |

统一规则：**所有路径都从 `state_file` 同目录推导**（`stateSibling`），改 `state_file` 时数据整体搬移，不需要为新文件加配置项。出处 `cmd/server/main.go:44-56`、`:312-345`。

## 消息队列 / 缓存

**无**。唯一的远程存储是可选 Redis（Upstash），且是**镜像/备份**角色，不是主存储：

- 未配置 `upstash.url` → `Noop`，纯内存模式一切功能照常（`internal/redisstore/redisstore.go:58-60`）。
- Ping 失败 3s 超时 → 降级 Noop + 警告，不阻塞启动（`:79-84`）。
- 写全 fire-and-forget：写槽信号量 8、单写超时 5s、失败只 debug 日志（`:26`、`:130-147`）。
- Key：`wb2api:bind:<hash>`（会话粘性）、`wb2api:state`（池快照），TTL 7 天（`:22`、`:47-51`）。
- 停机排空：`Close` 先关写入再 `wg.Wait`，10s 兜底（`:168-183`）。

## 出站 HTTP 语义（`internal/upstream/transport.go`）

| 参数 | 值 | 目的 |
|---|---|---|
| `DialContext` 超时 | 10s | 建连 |
| `TLSHandshakeTimeout` | 10s | 握手 |
| `ForceAttemptHTTP2` | false + 空 `TLSNextProto` | **真正禁用 h2**（上游对 h2 指纹敏感） |
| `MaxIdleConns` / `MaxIdleConnsPerHost` | 100 / 30 | 连接复用 |
| `IdleConnTimeout` | 30s | 短 keepalive |
| `ResponseHeaderTimeout` | 60s 默认，main 按 `upstream.header_timeout_seconds` 覆盖 | SSE 首字节上限 |
| 失败清池 | `CloseIdleConnections()` | 传输层错误后重建连接 |

出处 `transport.go:22-50,126-174`；接线 `cmd/server/main.go:165-171`。

**无出站代理支持**：全仓未查出 `Proxy`/`ProxyFromEnvironment`。需要代理时只能靠宿主网络。DNS 可覆盖：`dns_servers` / `WB2A_DNS` → `NewDNSDialer`（`PreferGo`，多台按序、单台 5s、无端口补 53），典型用途是 Android（无 `/etc/resolv.conf`）与 DNS 污染环境（`transport.go:78-124`）。

## 上游供应商

唯一上游是腾讯 CodeBuddy 的非公开接口，三族 base：

| realm | chat base | billing base | 判定依据 |
|---|---|---|---|
| cn | `https://copilot.tencent.com` | `https://www.codebuddy.cn` | 默认（`internal/upstream/client.go:897-898`） |
| global | `https://www.codebuddy.ai` | 同 chat | auth `domain` 后缀 `codebuddy.ai`/`workbuddy.ai`（`internal/loginsite/loginsite.go:112-136`） |
| web（仅领奖） | — | `https://www.workbuddy.cn` | 任务 claim 专用域（`client.go:900-902`） |

可选第三方：`models.dev`（`https://models.dev/api.json`，4.7MB 单文档）仅用于 `context_length` 四级查找链的第 4 级兜底，5s 超时、失败静默降级到 1M（`internal/upstream/modelsdev.go:1-30`）。

## 时间与地域

- 上游「自然日」（签到、活跃、夜猫子窗口、积分到期）全部按**北京零点**切日 → `internal/cst` 固定 `FixedZone("CST", 8h)`，因为网关可能跑在 UTC 主机上（`internal/cst/cst.go:1-24`）。
- 操作者统计口径（日报、日志切文件）**不**用 cst，保留宿主时区（`cst.go:15-17`）。
- 容器 `TZ=Asia/Shanghai`（`docker-compose.yml:15`）。
