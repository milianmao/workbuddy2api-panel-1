## 本分类的三条硬事实

1. **零框架**：无 Web 框架/ORM/日志库，标准库 + 21 个 internal 包 + 5 个 cmd（`go.mod:5-11`）。
2. **单二进制**：面板前端经 `go:embed` 内嵌，无构建步骤（`internal/panel/index.go:20-26`）。
3. **文件即数据库**：`state.json` / `usage.json` / `credit-history.json` 等全部从 `state_file` 目录推导（`cmd/server/main.go:44-56`）。
