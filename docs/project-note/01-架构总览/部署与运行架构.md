# 部署与运行架构

## 四种运行形态

| 形态 | 命令 | 适用 |
|---|---|---|
| 源码 | `go run ./cmd/server -config config.json` | 开发调试（`README.md:329-330`） |
| 单文件 | 直接跑 Release 里的 `wb2api.exe` | Windows/NAS，首次启动自动生成 `config.json`（含随机 api_key） |
| Compose | `docker compose up -d` | 服务器部署，卷挂载 auths/data/config.json |
| GHCR 镜像 | `docker run ghcr.io/misakano7545/workbuddy2api-panel:latest` | 免克隆免构建 |

`-config` 默认 `config.json`；文件不存在时 `WriteDefault` 生成含随机 `sk-` 密钥的推荐配置（`cmd/server/main.go:52-77`、`WriteDefault` 在 `cmd/server/config.go:494-521`）。生成失败（只读目录）则退回"纯默认 + env"，不阻塞启动。

## 端口与端点

| 项 | 值 | 出处 |
|---|---|---|
| 默认监听 | `:7863`（`listen`，归一化时补 `:` 前缀） | `cmd/server/config.go:369`、`:860-862` |
| Compose 映射 | `7863:7863` | `docker-compose.yml:17` |
| 健康检查 | `GET /healthz`，**恒无鉴权** | `internal/server/handler.go:211` |
| 面板 | `http://127.0.0.1:7863/panel/` | 启动横幅 `cmd/server/main.go:554-559` |
| Prometheus | `GET /metrics`，仅 `metrics.enabled=true` 时注册 | `internal/server/handler.go:220` |
| 补跑任务 | `POST /admin/tasks/{name}/run`，仅 `admin.enabled=true` | `internal/server/handler.go:215-218` |

`/healthz` 语义：`healthy>0` **且** 未全部占满在途 → 200，否则 503（`handler.go:271-274`）；响应带 `service:"workbuddy2api"` 字段与 `X-Service` 头，用于区分同端口残留的其他服务（`handler.go:290-296`）。实测空池返回：

```json
{"healthy":0,"realm_servable":{"cn":false,"global":false},"service":"workbuddy2api","total":0}
```

## 运行期依赖的目录

| 目录/文件 | 必需 | 缺失后果 |
|---|---|---|
| `auths/` | 否（空池可启动） | 0 账号，chat 全 503 `no_healthy_account` |
| `data/` | 否（自动创建） | 状态/用量/日志全部落在 `state_file` 同目录 |
| `config.json` | 否 | 自动生成推荐配置并打日志 |

Compose 挂载三个卷：`./auths`、`./data`、`./config.json`。**`config.json` 不能以目录形式出现**——缺失时 Docker 会把挂载点建成目录，导致容器启动失败（`docker-compose.yml:22-27` 注释）。因此宿主必须先 `cp config.example.json config.json`。

## 权限模型（容器）

- 镜像以 `app` 用户（uid 10001）运行（`Dockerfile:16,31`）；`/app/auths`、`/app/data` 预建并 chown（`Dockerfile:17`）。
- Compose 允许 `PUID`/`PGID` 覆盖（`docker-compose.yml:13`）。默认 10001 与宿主目录属主不一致时，写 `auths/*.json.tmp` 会 `permission denied`。
- 三种解法：以宿主 uid 运行 / `chown -R 10001:10001` / `user: "0:0"`（`docker-compose.yml:5-12`）。

## 构建

**Docker**（`Dockerfile`）：多阶段，`golang:1.26.10-alpine` 里一次编 4 个二进制（全部 `-trimpath -ldflags="-s -w"`、`CGO_ENABLED=0`），运行阶段 `alpine:3.20` + `wget ca-certificates tzdata python3 bash`，脚本去 CRLF 后 chmod 755。`HEALTHCHECK` 用 `wget -qO- http://127.0.0.1:7863/healthz`（30s 间隔，`Dockerfile:33-34`）。

**CI 二进制**（`.github/workflows/binaries.yml`）：
1. `go test ./...`（唯一测试步骤，`:28-29`）；
2. 版本号：tag 推送用标签名，否则 `TZ=Asia/Shanghai date +%Y.%-m.%-d.%-H%M`（`:34-39`）；
3. `go build -X main.appVersion=${VERSION}` 交叉编译 windows/linux/darwin × amd64/arm64 共 6 个（`:47-59`）；
4. 每个平台一个 zip（含 `config.example.json` + `README.md`）+ artifact；
5. tag 推送或手动触发时 `gh release create "v${VERSION}" dist/*.zip`（`:93-97`）。

**CI 镜像**（`.github/workflows/docker-ghcr.yml`）：QEMU + Buildx，`linux/amd64,linux/arm64`，PR 只构建不推送，`provenance: false`。main 推 `latest`/`main`/`sha-xxx`；日期版本号不是 semver，因此不会产生 `1.2.3` 之类的 tag。

## 版本号规则（`AGENTS.md:3-23`）

格式 `v2026.9.26.711`：日期 + 时不补零 + 分两位 + 不带秒。标签、Release、二进制用同一个号；二进制内不带 `v`（面板自己加）。**禁止**打 `v1.x` 标签、**禁止**手改 `appVersion`（`cmd/server/main.go:42` 恒为 `dev`，只有 CI 注入）。

本机（Windows/git-bash）没有 tzdata 时 `TZ=Asia/Shanghai date` 会**静默回落 UTC**，标签会早 8 小时；`AGENTS.md:12-22` 给出显式 +8h 兜底写法。

## 启动与停机时序

启动：config → auths → redis → pool（快照恢复 + 目录对齐）→ session → upstream → balance → scheduler → livecfg/usage/reqlog/credithist → panel → handler → taskJobs 恢复 → `go sch.Run` → 余额刷新 / 补领清扫 / 告警 → 异步预热模型倍率 → `ListenAndServe`（`cmd/server/main.go:58-508`）。

停机（SIGINT/SIGTERM）：`p.Flush()` 先落盘 → `srv.Shutdown(5s)`（`main.go:496-503`）；defer 链再 `pool.Close()`（最后一次 Flush）→ `store.Close()`（排空在途 Redis 写）。顺序不可颠倒，否则最后一笔镜像写会丢（`main.go:96-101` 注释）。

HTTP 服务参数：`ReadHeaderTimeout: 30s`、`ReadTimeout: cfg.ServerReadTimeoutDur`（默认 300s，`"0"` 不限）、`IdleTimeout: 120s`；**无全局 `WriteTimeout`**——长流式生成合法时长可达数分钟，写超时会误杀在途 SSE（`main.go:481-499`）。

## 配置加载顺序

`Default()` → （文件存在时 `safefile.Read` + `ParseConfigInto`）→ `applyEnv`（`WB2A_*` 非空才覆盖）→ `normalize()`（补默认 + 校验）（`cmd/server/config.go:446-472`）。`ParseConfig` 不读 env（`:486-488`），供面板保存路径做纯文件校验。

环境变量共 33 项（`applyEnv`，`:524-654`），`EnvironmentManagedFields()` 另用表驱动列出 38 条 env→字段映射供面板禁用输入框（`:662-709`）。

配置热生效分层：`livecfg`（api_key/soft_rate/脱敏/来源记录/hidden/aliases）、`pool.*` setter、`schedule.*`、budget 立即生效；`listen`/`auth_dir`/`state_file`/`upstream.*`/`prompt.*`/`upstash.*`/`session_sticky.*`/`admin`/`metrics`/`alerting`/`logging` 归档三项/`server.read_timeout` 需重启（`cmd/server/main.go:763-800`）。
