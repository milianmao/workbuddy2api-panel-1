## 六条最容易违反的规定

| # | 规定 | 违反后果 |
|---|---|---|
| 1 | 禁止手改 `appVersion`（`cmd/server/main.go:42` 恒 `dev`） | 发版号与二进制不一致 |
| 2 | 禁止打 `v1.x` 标签 | 与上游语义冲突，Release 混乱 |
| 3 | 新增热配置字段必须同时改 `cmd/server/main.go:305-314` 与 `:693-700` | 面板保存后该字段被清成零值 |
| 4 | 新增环境能力（node/权限/网络）的测试必须门控 skip | CI 与本地结果分裂 |
| 5 | `app.js` 纯函数不得依赖 DOM 全局 | 前端测试静默 skip，失去保护 |
| 6 | 不在 Windows 检出上跑 `gofmt -w` 批量改写 | CRLF → LF 全仓 diff |
