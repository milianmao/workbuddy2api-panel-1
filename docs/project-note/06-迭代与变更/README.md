## 使用优先级（fix-bug-workflow Step 1）

1. 先查 [已知问题与陷阱](已知问题与陷阱.md) 是否命中同类现象——22 条里有 4 条是"整池打光"级别的事故。
2. 再查 [../03-核心数据业务流/](../03-核心数据业务流/README.md) 定位数据流路径与异常分支。
3. 最后查 [../02-功能结构和策略/关键设计决策.md](../02-功能结构和策略/关键设计决策.md) 确认当前行为不是"设计如此"。
