## 三条最容易踩的边界

1. **`pool` 不认识 `upstream`**：倍率靠 `SetModelRateOf` 回调注入。想在上游加能力而 pool 要用，走注入，不要 import。
2. **`scheduler` 不认识 `panel`**：成长队列执行体在 panel，靠 `SetGrowthRunner` 回注。
3. **护栏不改透传字节**：唯一例外是提示词降级（`internal/server/degrade.go`），它按设计改写 system。
