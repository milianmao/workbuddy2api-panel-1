## 🤖 给 AI 的阅读指南

1. **按需逐层深入**：先读本页，再读命中分类的 L2（约 40 行），只在需要具体实现细节时才读 L3。
2. **L3 不超过 300 行**：若某篇超了，说明该拆；当前最大的是 `06/已知问题与陷阱.md`（22 条陷阱，按 P 编号定位）。
3. **信息只存一处**：同一事实不会在两篇 L3 里重复完整定义，跨文档一律用 `→ 详见 [文档名]` 形式的相对链接引用。
4. **业务流文档可直接被机器解析**：`03-核心数据业务流/` 下 6 篇均已通过 `scenario-oracle-builder/scripts/extract.py` 校验（coverage 6/6，normal/error/boundary 各 6）。
5. **代码行号即证据**：所有断言都带 `path:line`。若行号漂移，以代码为准并在 `06/变更日志.md` 记一笔。
6. **不要相信 README 的过时表述**：已实证 4 处与代码不符（`prompt.mode` 默认值等），清单在 `06/迭代与变更/变更日志.md`「构建过程中发现的事实性偏差」。
